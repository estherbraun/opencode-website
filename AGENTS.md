# Agent constraints

- Site purpose: a half-marathon training hub for first-time runners preparing for a fall race.
- Tone: encouraging, practical, plain language. No medical advice beyond "check with a doctor before starting a plan."
- Use only index.html, style.css, and script.js. No frameworks, dependencies, or CDNs.
- Served locally with `python3 -m http.server 8000 --bind 127.0.0.1`. Relative links only. No deployment.
- Layout must work from 360px to wide desktop widths with no horizontal scrolling.
- All controls must be real <button> elements, keyboard-operable, with a visible :focus-visible style.
- Body text at least 16px with good color contrast.
- No placeholder or lorem ipsum text.
- No API keys, tracking scripts, accounts, or credentials.
