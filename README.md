
A half-marathon training hub for first-time runners preparing for a fall race.

## Prerequisites
- Python 3
- A web browser

## Setup
1. `git clone https://github.com/estherbraun/opencode-website.git`
2. `cd opencode-website`
3. `git switch website`

## Run
`python3 -m http.server 8000 --bind 127.0.0.1`

Open http://localhost:8000 in your browser.

Stop the server: press Ctrl+C in the terminal running it.
